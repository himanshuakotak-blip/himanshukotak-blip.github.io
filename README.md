# Himanshu Kotak — Personal Website (Version 1)

A lightweight static personal-authority website built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — page content + SEO metadata + Person structured data
- `styles.css` — responsive visual design
- `script.js` — small mobile-menu/year behavior
- `assets/himanshu-kotak.jpg` — profile image supplied in the conversation

## Run locally
Open `index.html` in a browser. No Python or server is required.

## Deploy to GitHub Pages
1. Create a new GitHub repository, e.g. `himanshu-kotak-site`.
2. Upload all files/folders from this directory.
3. GitHub → Settings → Pages → Deploy from branch → `main` → `/ (root)`.
4. Save. GitHub will provide the public site address.

## Before publishing
- Confirm the preferred personal domain name.
- Confirm the final public contact numbers/emails.
- Add the exact C-PHI DrillTech website URL if one is to be linked.
- Replace/adjust any project figures or wording that you want to publish publicly.
- Add a Google Search Console property after the site is live.
